# 外贸经营驾驶舱

深蓝科技大屏风格，围绕业务、团队、客户、流量、结构、效率六个维度展示和处理外贸经营信息。

## 打开

开发服务运行时访问 http://127.0.0.1:5173/ 。

GitHub Pages 在线预览：https://zx1014811644-source.github.io/global-trade-cockpit/

`main` 分支更新后，GitHub Actions 会自动重新构建并发布在线预览。

本仓库与 GitHub Pages 演示页面均为公开访问。

重新启动：在本目录运行 `npm run dev -- --port 5173 --strictPort`，或双击 `启动看板.command`。首次在其他电脑运行需安装 Node.js，然后执行 `npm install`。

`npm run build` 输出可部署静态资源到 `dist/`；`npm run preview` 可本地预览构建产物。不要直接双击 index.html，应通过本地服务打开。

## 已实现

- 业务：询盘/RFQ → 报价 PI → 定金到账 → 生产验货 → 订舱交单 → 尾款结汇；各节点可查看明细；德国信用证不符点与美国尾款逾期 12 天可展开处置建议。
- 团队：商机数、平均首响、转化率；显示首响超过 4 小时的异常数量；超过 7 天未推进订单可重分配，历史耗时保留。
- 客户：A/B/C 分层；超过 60 天未复购自动进入提醒队列；可创建本地三阶段唤醒计划。
- 流量：P4P、RFQ、LinkedIn、官网 SEO 的商机数、转化率、点击量和 CTR；阈值触发质量预警。
- 结构：区域出口合同金额分布、T/T、L/C、O/A 结算构成；可查看明细及信保资料准备清单。
- 效率：首响、报价、审证、交单、回款 SLA；根据超标节点创建提效清单。
- 联动：中央区域筛选或点击区域图，联动订单、客户、团队、渠道及结算金额；SLA 明确标注全公司演示基准，不按区域伪造数值。
- 演示处理结果保存在当前浏览器 localStorage 中，刷新后恢复。

## 数据与能力边界

所有业务记录都是固定演示样例，不是真实经营数据。金额以执行订单合同金额汇总，不代表当月收入或真实应收敞口。报价阶段使用已转化商机作为演示代理口径；各阶段为累计进入量，不应相加。

AI 辅助目前是规则模板演示，没有连接模型接口。唤醒、重分配和风险受理仅变更当前浏览器的本地状态，不发送消息，不写入外部 CRM，不执行银行、物流或保险操作。风险加入处理计划表示已受理，不代表风险已解除。

正式使用需接入业务数据库、平台指标、实际 SLA、权限与审计，以及邮件/CRM/AI 服务。RFQ、广告和社媒需先统一各自平台的指标定义。
