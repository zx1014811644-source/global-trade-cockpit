# 外贸经营驾驶舱

参考：用户提供的深蓝科技大屏；设计稿见 design-concept.png。

核心目标：在一个屏幕内呈现六维经营态势，从风险发现进入处置。先交付前端演示，数据与操作明确标注模拟。

执行步骤：建立统一演示订单/客户/线索模型；实现六维聚合与区域筛选；开发风险处置与本地任务状态；验证桌面、移动端和核心交互。

风险提示：未连接 CRM、平台投放、银行、物流或信保系统；金额和比率均为样例；规则模板不是银行审单或信保承保意见；页面不发送消息。

衡量指标：六维筛选使用同一数据集；异常严格按首响>4小时、未复购>60天、订单停滞>7天判定；核心交互可操作；移动端无横向溢出。

## 设计约束
- 背景 #030d26，面板 #05152b，青色 #35e7ff，正文 #d5edff，次级 #7e9aba，红色 #ff6476，黄色 #efc66b。
- 三列主舞台：业务/团队在左，地球居中，客户/流量在右；底部结构和效率两等宽面板。
- 标题 angular HUD，面板细线与四角高光；不使用圆角卡片和普通管理后台侧边栏。
- 字体 PingFang SC / Microsoft YaHei；数字用 DIN Alternate / Arial Narrow / monospace；主标题32px、模块16px、正文12px、数字24px。
- 真实文本与控件用 HTML/React；地球使用单独生成资产，边缘渐隐融合深蓝背景。
- 控件：区域下拉、全屏、六维导航、异常详情、重分配、唤醒旅程、渠道详情、SLA辅助。
- 主屏文案来自用户六维需求；附加文案仅用于数值单位、演示声明、筛选和操作反馈。
- 有意调整生成稿：链路采用询盘/RFQ、报价PI、定金到账、生产验货、订舱交单、尾款结汇；SLA采用首响、报价、审证、交单、回款，不采用生成稿偏离需求的标签。
- 动效仅用于连线和轻微光晕；支持 prefers-reduced-motion。

## 素材
内置 Image Gen 生成 concept 与 globe。地球提示词：独立的亚洲视角全息地球、青蓝大气层、城市光点及全球贸易轨道，深海军蓝背景，不含文字、Logo 或 UI。概念提示词围绕完整六维中文外贸驾驶舱、深蓝青色科技风、中央地球、四周四块面板及底部两块面板。
