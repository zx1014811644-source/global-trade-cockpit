# 验证与视觉对照

## 方法

先通过 Codex 内置浏览器加载本地页面并读取无错误的 UI 和控制台。内置截图发生缩放/拼接异常，Chrome UI 会话连接超时，因此改用本机 Chrome 的 Playwright 无头模式完成截图及工作流测试。长页面 fullPage 截图亦存在重复拼接，最终采用真实视口截图与滚动到底部截图。

已用 view_image 直接打开概念稿和最终桌面、手机截图作同轮比较。

## 视口

- 1920×1080：与用户参考图原始尺寸相同，完整大屏，无横向或纵向溢出。
- 1440×900：无横向溢出；内容高约999px，允许纵向滚动，优先保持文字与操作可读。
- 390×844：无横向溢出；地球优先、六维模块单列纵向排列；弹窗位于视口内。
